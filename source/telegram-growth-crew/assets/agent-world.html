    How it works together

    PostsBroadcaster drafts→Approval inbox + Telegram DM→You tap Approve→Your bot posts to the channel
    AdsYou book an ad→Agent World bot makes an invite link→People join via that link→Ad Tracker: cost per subscriber
    DealsNegotiator drafts→You approve→You send it yourself from your own Telegram
    WelcomeSomeone taps your ad link→Agent World bot lets them in→Sends "Welcome @name!" in a private chat

    What the real connection needs

    1. Create the Agent World botIn Telegram, open @BotFather and send /newbot. You get a token.
    2. Make both bots admin of your channelYour bot: post messages. Agent World bot: invite users via link.
    3. Put the tokens on a small server, never in this pageThe server runs the agents, talks to Telegram and keeps the keys safe.
    4. Channel numbersJoins come from the invite links. Views per post and other channels' stats come from TGStat or Telemetr, because the Telegram bot API does not give them.
    5. Claude as the brainA Claude API key on the same server lets each agent write, score and plan for real.
